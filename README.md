# Muscu

Application PWA personnelle de suivi de musculation.

## À envoyer dans le dépôt GitHub
- `index.html`
- `manifest.json`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

Les séances sont enregistrées localement dans le navigateur du téléphone.  
Pense à utiliser **Réglages > Exporter JSON** avant un changement de téléphone ou de navigateur.

## Publication GitHub Pages
Dans le dépôt : **Settings > Pages > Deploy from a branch > main / root**.
